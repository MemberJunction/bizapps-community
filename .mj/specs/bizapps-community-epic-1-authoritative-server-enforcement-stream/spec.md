# Epic 1: Authoritative Server Enforcement Specification

This document defines the requirements for authoritative server-side enforcement of community actions.

## Contracts
- CR-01: Ownership & UUID Validation
- CR-02: Fail-Closed Pin/Lock & Role Resolution
- CR-03: Direct Answer Entity Acceptance & Canon Authorization
- CR-04: Transaction Propagation & Checked Derived Saves
- CR-05: Ownership-Authorized Reaction Toggle
- CR-06: Strict Metadata Provider Gating
- CR-07: Atomic Transaction in Canon Promotion
- CR-08: Harness & Production Integration Tests
